第一次安装

  1. 下载并解压 ZIP，把 Mote.app 拖进「应用程序」，再打开。
  2. 这是暂未经过 Apple 公证的内测版。macOS 可能阻止首次打开。确认下载来自本页后，可在「系统设置 → 隐私与安全性」里查看「仍要打开」，由你本人决定是否允许。
  3. 想使用自动活动记录时，按 Mote 提示开启「辅助功能」。仅用于读取应用名和窗口标题。你可以在 Mote「记录」里关闭自动记录。
